# ANALYSIS

The key issue is that the model is predicting almost all the samples as negative. This is indicated by the zero recall for 11/14 classes and zero precision for 11/14 classes. This is likely causing the very low F1-Scores, as F1-Score is the harmonic mean of precision and recall.

There are several possible reasons for this:

1. **Threshold at 0.5**: Even though the threshold is set to "auto", it seems the threshold optimization might not be functioning as intended, as the model is making almost all negative predictions. The threshold optimization strategy should be revisited.

2. **Imbalanced Data**: The data is highly imbalanced, with some classes having less than 1% positive samples. This often leads the model to predict the majority class (negative in this case) most of the time, as it's the safest bet to minimize loss.

3. **Loss Function**: The model is using FocalLoss with gamma=3.0 and alpha=0.75. The high alpha value might be causing the model to focus too much on the majority class. Also, the gamma parameter might not be high enough to make the model focus on hard, misclassified examples.

Comparing this iteration (12) with the previous iterations, the F1-Score has been consistently low. Iteration 4 had the highest Avg F1-Score of 0.1076, but it's still far below the desired level. The changes made in the following iterations have not been successful in improving the F1-Score.
