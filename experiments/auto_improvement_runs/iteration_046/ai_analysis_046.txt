The Average F1-Score, Recall and Precision have increased to 0.2063, 0.4401, and 0.1505 respectively, while the Average AUC score is at 0.7682. However, some key issues persist:

- **Overfitting**: The validation loss is higher than the training loss, suggesting the model might be overfitting the training data. This is further supported by the fact that our model's performance is significantly worse on the test set than on the training set.

- **Class Imbalance**: Despite the use of SMOTE for data augmentation and dynamic class weights, the model is still struggling with the class imbalance issue. This is evident from the low Recall scores for certain classes. 

- **Thresholding**: The model seems to be predicting almost all samples as negative. This could be due to the currently applied threshold, which might be too high for certain classes. We've set threshold optimization to "per_class_f1_score", but it's not clear if this is having the desired effect.

- **Loss Function**: The Focal Loss function parameters (alpha and gamma) might need further tuning. The current setup may not be effectively managing the class imbalance, particularly for rare classes.
