=== ANALYSIS ===

1. The model is predicting almost all samples as negative because of the significant class imbalance in the dataset. This is a common issue in machine learning where the model primarily learns the characteristics of the majority class and, therefore, is biased towards it. Since the negative examples vastly outnumber the positive examples, the model learns that it can achieve a high accuracy just by predicting negatives.

2. Improving recall while maintaining good AUC can be achieved by addressing the class imbalance directly. This can be done through several methods such as oversampling the minority class, undersampling the majority class, or synthesizing new examples in the minority class (SMOTE, ADASYN). However, this needs to be carefully managed as oversampling can lead to overfitting, and undersampling can lead to loss of information.

3. The current learning rate might be too high, causing the model to converge quickly to a sub-optimal solution. A lower learning rate would allow the model to learn more nuanced features, which might improve class prediction. Additionally, tweaking the gamma parameter of the Focal Loss function can help to put more focus on hard, misclassified examples.

4. Implementing per-class threshold optimization could be beneficial. The current threshold of 0.5 is likely inappropriate due to the class imbalance. By optimizing the threshold for each class, we can maximize the F1-score, which is a good balance between precision and recall.

5. The current Focal Loss function is designed to handle class imbalance by using a tunable focusing parameter gamma and a balanced class weight. However, the gamma value can be further optimized. Higher gamma values put more focus on hard, misclassified examples.
