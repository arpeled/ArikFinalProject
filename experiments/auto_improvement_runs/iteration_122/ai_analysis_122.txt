================================================================================
INTERPRETATION
================================================================================

The experiment confirms that the Hernia class CAN learn something from increased
exposure, but the current intervention (10x oversampling + mild augmentation)
is insufficient for reliable detection.

Possible explanations for weak performance:
1. Visual features of Hernia may be subtle and overlap with negative cases
2. 10x oversampling increases Hernia from 0.2% to 2.1%, still quite rare
3. The frozen backbone limits feature learning capacity
4. Hernia may require more specialized model architecture

================================================================================
RECOMMENDATIONS FOR FUTURE EXPERIMENTS
================================================================================

1. HIGHER OVERSAMPLE FACTOR
   - Try 25x or 50x to further increase Hernia exposure
   - Target effective prevalence of 5-10%

2. FOCAL LOSS FOR HERNIA
   - Replace BCE with Focal Loss for Hernia class
   - Down-weight easy negatives, focus on hard examples

3. UNFROZEN BACKBONE
   - Allow partial backbone fine-tuning (DenseBlock4)
   - May help learn Hernia-specific low-level features

4. HERNIA-SPECIFIC HEAD
   - Add dedicated Hernia classification branch
   - Separate from main multi-label head

5. EXTERNAL HERNIA DATA
   - Augment training with external Hernia-positive images
   - Address fundamental data scarcity issue

================================================================================
CONCLUSION
================================================================================

The HERNIA_OVERSAMPLE experiment achieved its diagnostic objective by
demonstrating that label-aware oversampling can force weak class detection.
The implementation is correct and functional. However, the 10x oversample
factor produces only marginal Hernia detection capability (5 TP, 371 FP).

This iteration serves as a baseline for future Hernia-focused interventions
and confirms that more aggressive approaches are needed for clinically
useful Hernia detection.
