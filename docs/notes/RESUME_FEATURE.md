# Resume Feature - Auto-Improvement Pipeline

The auto-improvement pipeline now supports **automatic resume** functionality, allowing you to continue training from where you left off across multiple sessions.

## 🎯 Why Resume?

Training 10 iterations takes **~25-30 hours** for the full dataset. The resume feature allows you to:

✅ **Split work across days** - Run 3 iterations today, 7 tomorrow
✅ **Recover from interruptions** - System crashes, power loss, etc.
✅ **Adjust iteration count** - Start with 5, then add 5 more if needed
✅ **No manual tracking** - Automatically detects and continues from last iteration

## 🚀 How to Use

### Option 1: Interactive Script (Easiest)

```bash
./run_auto_improvement_uv.sh
```

**The script will automatically:**
1. Detect previous iterations
2. Ask if you want to resume
3. Show what iteration it will continue from
4. Run the specified number of additional iterations

### Option 2: Command Line

```bash
# Run 3 iterations initially
uv run auto_improvement_loop.py --iterations 3

# Later: Resume and run 7 more
uv run auto_improvement_loop.py --resume --iterations 7
```

## 🔍 How It Works

### Detection Logic

When `--resume` is enabled, the system:

1. **Scans output directory** for `iteration_*/` folders
2. **Finds the latest** completed iteration number
3. **Looks for next config** in two places:
   - `config_iteration_NNN.yaml` (preferred - from AI's previous suggestion)
   - `output_dir/iteration_NNN/config.yaml` (fallback)
4. **Continues numbering** from last iteration + 1

### What Gets Reused

✅ **Configuration** - Uses AI-suggested config from last run
✅ **Iteration numbering** - Continues sequentially (4, 5, 6...)
✅ **Output directory** - Appends to same `auto_improvement_runs/`
✅ **Iteration history** - All iterations in one place

### What Doesn't Get Reused

❌ **Models** - Each iteration trains from scratch (new model)
❌ **Results** - Each iteration generates fresh test results
❌ **Logs** - New log file for each run session

```bash
# Day 1
```



## 🛠️ Advanced Usage

### Manual Resume from Specific Config

```bash
# Use a specific config file to start
uv run auto_improvement_loop.py \
    --config config_iteration_005.yaml \
    --iterations 5
# Note: Without --resume, this starts at iteration 1 with that config
```

### Resume with Different Iteration Count

```bash
# Initially planned 10, but want to extend
uv run auto_improvement_loop.py --iterations 10
# (completes iterations 1-10)

# Add 5 more
uv run auto_improvement_loop.py --resume --iterations 5
# Runs iterations 11-15
```

### Fresh Start (Ignore Previous Runs)

```bash

# Or use different output directory
uv run auto_improvement_loop.py --iterations 10 --output-dir new_experiment
```

## ⚠️ Important Notes

### Resume Doesn't Transfer Models
Each iteration **trains a new model from scratch**. Resume only:
- Continues the iteration numbering
- Uses AI-suggested config from previous run
- Appends to same output directory

### Config Chain is Preserved
```
Iteration 1 (baseline config)
  → AI suggests changes
  → Creates config_iteration_002.yaml

Iteration 2 (uses config_iteration_002.yaml)
  → AI suggests changes
  → Creates config_iteration_003.yaml

[RESUME HERE]

Iteration 3 (uses config_iteration_003.yaml)
  → Continues the optimization chain!
```

### No Resume = Fresh Start
Without `--resume`, the pipeline **always starts from iteration 1** using the baseline config.

## 🐛 Troubleshooting

### "No previous iterations found"
```
Resume mode enabled - searching for previous iterations...
⚠️  No previous iterations found in output directory.
Starting from iteration 1 with baseline config.
```

**Cause:** Output directory is empty or no `iteration_*` folders exist.
**Solution:** Run without `--resume` first to create initial iterations.

### "Could not find config for iteration N"
```
⚠️  Could not find config for iteration 3
Falling back to baseline config
```

**Cause:** Config file missing (deleted or never created).
**Solution:** System falls back to baseline config automatically. Safe to continue.

### Wrong Iteration Numbers
If iterations are numbered incorrectly:
1. Check `auto_improvement_runs/` for actual iteration folders
2. Manually specify the config you want to use with `--config`

### Resume from Different Machine
To resume on a different machine:
1. Copy the entire `auto_improvement_runs/` directory
2. Copy all `config_iteration_*.yaml` files
3. Run with `--resume` as normal
